# ux-principles

Правила взаимодействия в трёх слоях и проверка, которая удерживает каждое
правило в своём слое.

Они выделены из UX-страницы одного продукта, где из пятнадцати правил двенадцать
оказались общими, четыре требовали курсора или окна, а собственно продуктовыми
были только разобранные примеры. Это соотношение и есть причина существования
репозитория: почти всё, что команда узнаёт про взаимодействие, переносимо — и
остаётся запертым в одном репозитории, потому что никто не отделил его от улик.

## Слои

| Слой | Что там |
| --- | --- |
| [`rules/core.ru.md`](rules/core.ru.md) | принципы для любого интерфейса: считай шаги и взвешивай частотой, действие живёт на объекте, нет подтверждений для обратимого, обрезай только достижимое, предупреждение висит, пока есть что делать |
| [`rules/desktop.ru.md`](rules/desktop.ru.md) | курсор, клавиатура, окна, оболочка: путь назад по одному слою, вёрстка не ездит под курсором, три маршрута ввода, заменил часть оболочки — унаследовал её обязанности |
| страница самого продукта | правила этого продукта и случаи с числами шагов |

Плюс [`rules/process.ru.md`](rules/process.ru.md) (как записывается сценарий,
как считаются шаги, что обязан содержать запрос на возможность) и
[`rules/positions.ru.md`](rules/positions.ru.md) — позиции, которые обоснованы,
но не всеобщи, отделённые намеренно.

## Две мысли, которые стоит забрать, даже если не брать остального

**Проверка на подъём.** Принцип общий, только если формулируется без упоминания
устройства ввода, платформенной сущности и частей вашего продукта. Применять её
надо в неприятную сторону: общий свод ломается тем, что всё уползает вверх.

**Улики наверх не поднимаются.** Случай, породивший правило, остаётся с
продуктом. Числа шагов и снимки экрана протухают, и именно они делают свод
нечитаемым для того, кто этот случай не пережил.

## Как пользоваться

См. [`INSTRUCTIONS.ru.md`](INSTRUCTIONS.ru.md) — агент копирует `rules/*` в
целевой репозиторий как `.claude/rules/ux/` и добавляет одну строку в его
`AGENTS.md`.

Устройство такое же, как у
[llm-wiki-tags](https://github.com/mpashka/llm-wiki-tags): каноничная
формулировка живёт в `rules/`, README её описывают, `INSTRUCTIONS*` дают
процедуру.

Английский оригинал: [`README.md`](README.md).
