# Russian Empire 1900-1920 Project Index

Проект вычислительной истории: построить временной ряд языка общественного кризиса в 1900-1920 годах и получить проверяемый демонстратор пользы ИИ для историка.

## Навигация

| Путь | Описание |
| --- | --- |
| `request.md` | Исходный запрос и критерий результата: проверяемый “вау-эффект” для историка. |
| `AGENTS.md` | Рабочие инструкции для отдельного Codex-инстанса, включая правила llm-wiki. |
| `plan.md` | Пошаговый план исследования от корпуса до финальной демонстрации. |
| `context/` | Методологический и предметный контекст для агента. |
| `context/index.md` | Навигация по контекстным файлам проекта. |
| `context/research-design.md` | Исследовательский дизайн: гипотезы, метрики, варианты результата. |
| `context/coding-schema.md` | Схема признаков для LLM/ручной разметки текстов. |
| `context/sources.md` | Стартовая карта источников и стратегия проверки доступности корпусов. |
| `context/sources-verified.md` | Проверенный предварительный список источников и решение по пилотному корпусу. |
| `context/acquisition-check.md` | Проверка конкретных путей получения пилотных источников перед скачиванием/OCR. |
| `docs/` | Рабочие подзадачи и исследовательские заметки, не являющиеся корпусом или финальными результатами. |
| `data/` | Данные проекта: сырой корпус, очищенные тексты, таблицы признаков. |
| `scripts/` | Воспроизводимые скрипты сбора, очистки, разметки и анализа. |
| `outputs/` | Графики, таблицы, черновики итогового доклада и демонстрационные материалы. |

## Текущий статус
