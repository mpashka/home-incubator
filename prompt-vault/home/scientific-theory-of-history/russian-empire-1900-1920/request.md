# Запрос проекта

Создать отдельный проект по варианту “Российская империя / революционный цикл, 1900-1920” как демонстратор возможностей современного ИИ для историка.

Основная цель: получить проверяемый, эффектный результат, который историк мог бы оценить как содержательный. Пример желаемого “вау-эффекта”: показать на временном ряду 1900-1920, как формировалась революционная ситуация, чем 1905 отличался от 1917, и какие изменения языка/социальных ориентиров видны после революции.

Проект должен быть готов к запуску отдельного инстанса Codex: в нем должен быть контекст, рабочий план, правила ведения llm-wiki и индексов `index.md`.
