## Самопроверка

```bash
./bssid-show check
```

Ожидается `check: ok`: проверяются разбор `iw scan`, нормализация BSSID, CSV-экранирование и
наличие hostname в последней колонке каждой строки замера.

## Живой адаптер

1. При подключённом Wi-Fi запустить `./bssid-show bssid`: вывод совпадает с
   `iw dev … link`, адрес из `aps.txt` превращается в имя комнаты. Запуск без аргументов
   сначала показывает все команды, затем тот же статус.
2. Запустить `./bssid-show roam`: текущая точка удаляет ноутбук на 10 секунд, команда показывает
   новый BSSID либо через 20 секунд явно сообщает, что перехода не произошло.
3. Запустить `./bssid-show survey`, выполнить одну точку: `sudo iw scan` успешен, CSV создан
   в `home-config-secrets @/ansible/.configs/out/wifi-survey/`, в нём есть все видимые сети,
   ровно одна текущая помечена `connected=1`, везде `cached=0`, последняя колонка `device`
   равна hostname ноутбука.
4. Отказать в `sudo`: команда завершается явной ошибкой и не засчитывает точку.
