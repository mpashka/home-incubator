# Реестр тегов

Родитель: [`index.md`](index.md).

Тег — плоский kebab-case slug `[a-z0-9-]+`, записанный токеном `@tag:<slug>`. Когда понятие
появится и в коде, и в документации, один и тот же токен ставится в Markdown front matter и
в комментарии непосредственно над кодовым элементом.

## Теги

| тег | смысл |
|---|---|
| `@tag:bssid-read` | живое чтение текущих SSID, BSSID и RSSI через `iw link`; ошибка не заменяется старым значением |
| `@tag:ap-map` | редактируемая карта BSSID→SSH-точка, hostapd-интерфейс и имя; бит `0x02` первого байта сбрасывается, адрес сравнивается целиком |
| `@tag:site-survey` | интерактивный обход контрольных точек со свежим сканом всех видимых BSSID; Android-совместимый CSV сразу сохраняется в Ansible-проект для анализа |

## Поиск

```bash
grep -rn "@tag:<slug>" .
grep -oE "@tag:[a-z0-9-]+" path/to/file
grep -rhoE "@tag:[a-z0-9-]+" . | sort -u
```
