# Home Wi-Fi Roaming (Android)

Виджет на домашний экран 1x1: показывает **комнату**, в которой стоит точка доступа, к которой
сейчас подключён телефон (коридор, кухня, спальня), и **уровень сигнала**.

Правила работы в проекте — [`AGENTS.md`](AGENTS.md), структура каталога —
[`index.md`](index.md).

## Зачем

Дома три точки доступа. На каждой поднята общая роуминговая сеть `m260` / `m260G` — одно имя
на всех трёх, иначе быстрый роуминг (802.11k/r) не работает в принципе. Из-за этого имя сети
больше не говорит, где ты: точку задаёт только BSSID, а он выглядит как
`d4:da:21:71:10:07` и в уме не читается.

Готовый [WiFi Widget](https://f-droid.org/packages/com.w2sv.wifiwidget/) показывает BSSID, но
именно сырой — поэтому и понадобилось своё.

## Что делает

1. **Виджет** — показывает текущую точку иконкой комнаты, крупно и читаемо, плюс полоса
   уровня сигнала.
2. **Обход точек замера** — отдельный экран в приложении: ведёт по заранее заданному
   маршруту и пишет CSV с уровнями всех видимых сетей. Нужен не для показа, а чтобы
   подстраивать мощность точек под роуминг; список маршрута и обработка результата живут
   в `home-config-secrets @/ansible/docs/wifi.md`.

Переключение на выбранную точку **решено не делать**: на стоковом Android оно недостижимо
(разбор — в [`docs/android-wifi-api.md`](docs/android-wifi-api.md)), а подводить пользователя
к системной панели Wi-Fi он не просил. Списки сетей, графики, история, темы — тоже не нужны.

## Как это работает

Виджет ничего не читает сам: `onUpdate` приходит в фоне, а в фоне система BSSID не отдаёт.
Нажатие открывает прозрачную активность на мгновение — этого хватает, чтобы приложение
считалось передним планом, — она читает Wi-Fi, обновляет виджет и закрывается. Между
нажатиями виджет гасит иконку, когда показания старше десяти минут: он не делает вид, что
знает, где вы сейчас.

## Сборка

```bash
./build.sh          # build/app.apk
./build.sh install  # собрать и поставить/обновить на подключённом по adb телефоне
./build.sh receive  # принять один CSV замеров с телефона и завершиться
./build.sh check    # самопроверки карты BSSID→комната и HTTP-приёмника
```

## Обычный сценарий

1. Подключить телефон по USB с включённой отладкой и установить или обновить приложение:

   ```bash
   ./build.sh install
   ```

   Команда соберёт `build/app.apk` и выполнит `adb install -r`, сохранив данные приложения.

2. Перед обходом точек запустить одноразовый приёмник:

   ```bash
   ./build.sh receive
   ```

   Он слушает `http://192.168.2.122:8765/`, принимает один CSV в
   `~/Projects/home/home-config-secrets/ansible/survey-results/` и завершается. Другой каталог
   или порт передаются как аргументы: `./build.sh receive /tmp/surveys --port 9876`.

3. На телефоне закончить обход и нажать **«Отправить на ПК»**. Подробности и обработка ошибок —
   [`docs/survey-transfer.md`](docs/survey-transfer.md).

Нужны Android SDK (`$ANDROID_HOME`, платформа `android-36`) и JDK 17+. `$JAVA_HOME` на этой
машине показывает на JDK 8, поэтому скрипт берёт `java` из `PATH`; переопределяется
переменной `ANDROID_JDK`.
