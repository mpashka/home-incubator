# Реестр тегов

Тег связывает одно понятие в коде и в документации: один и тот же токен `@tag:<slug>` ставится
во всех местах, где понятие живёт, — и находится одним поиском.

## Теги проекта

| тег | понятие |
|---|---|
| `@tag:bssid-read` | чтение текущего BSSID: доступно только с `ACCESS_FINE_LOCATION` и включёнными службами геолокации, иначе система молча отдаёт заглушку `02:00:00:00:00:00`; в фоне требует отдельного разрешения. На HyperOS 16 настоящий адрес отдаёт только устаревший `getConnectionInfo()`, поэтому спрашиваются оба источника |
| `@tag:ap-map` | сопоставление BSSID с комнатой: второй BSS радио отличается только битом `0x02` первого байта, поэтому бит сбрасывается и адрес сравнивается целиком (по префиксу нельзя — у спальни и кухни совпадают пять байт). Запись карты — `BSSID что-рисовать [подпись]`: первое слово либо имя встроенной иконки, либо эмодзи, которое рисуется как есть |
| `@tag:site-survey` | обход точек замера: список точек приходит снаружи файлом, приложение ведёт по нему и пишет CSV с уровнями **всех** видимых BSSID. Нужен, чтобы подстраивать мощность точек под роуминг; потребитель — `home-config-secrets @/ansible/docs/wifi.md` |
| `@tag:survey-upload` | отправка CSV обычным `PUT`: основной путь — открытый HTTP на одноразовый приёмник в домашней LAN; запасной — HTTPS на app-server с клиентским сертификатом из Android KeyChain. Исходный файл всегда остаётся на телефоне |
| `@tag:ap-switch` | перевод телефона на выбранную точку: без root система этого не даёт, доступен только подвод пользователя к системной панели Wi-Fi; настоящий переход — `wpa_cli roam` с root или через Shizuku. **Функция не делается**, тег живёт только в документации |

## Формат тега

Короткий слаг из `[a-z0-9-]+`, записанный токеном `@tag:<slug>`.

- **Документация** — в YAML-заголовке файла: `tags: "@tag:bssid-read"`. Для каталога — в его
  `index.md`. Если тег относится только к одному разделу, строка ставится рядом с разделом.
- **Код** — в комментарии на языке файла, прямо над помеченным классом или функцией.
  В Kotlin/Java — `// @tag:<slug>`.
- Несколько тегов разделяются пробелом.
- Теги — для сквозных понятий, а не для разовых деталей.

## Поиск

```bash
grep -rn "@tag:ap-switch" .
```
