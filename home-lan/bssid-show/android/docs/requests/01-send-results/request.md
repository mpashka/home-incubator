В приложение есть функциональность: обойти контрольные точки
и выполнить в этих точках замеры сигнала. Это необходимо, чтобы более точно
подстроить мощности сигнала для переключения между BSSID.

Настройка роутеров openwrt реализуется в проекте ~/Projects/home/home-config-secrets/ansible

Остаётся открытым вопрос - как передать результаты замеров из приложения в ansible
Изначально был реализован вариант через локальные файлы приложения (телефона) + adb. Чем мне нравится adb - когда
ты подключаешь телефон проводом - он начинает заряжаться.
Я предложил способ через сервер (сейчас в инфраструктуре ansible уже есть сервер - надо просто добавить функцию),
но сейчас я думаю - это overengineering. Не удаляй код отправки результатов замеров из приложения через app server, но думаю есть способ проще.
Нам достаточно один файл перекинуть из телефона в конкретно этот ПК, для конкретного сценария настройки BSSID.
Поэтому вполне допустим сценарий - я что-то запускаю на ПК (возможно даже codex skill), открываю приложение в телефоне, хожу с телефоном по квартире, замеряю,
нажимаю кнопку и отправляю файл с результатами с телефона на ПК. Для передачи можно использовать сеть wifi, поскольку это LAN,
то защищать передачу нет необходимости - можно в открытом виде передать.

В приложении сценарий такой - я вхожу в режим "замерить мощность" - приложение мне говорит "встань туда, нажми замерить, подожди 30 секунд"
и по завершении предлагает несколько вариантов отправить файл (несколько кнопок):
- оставить на телефоне - можно потом забрать через adb
- скопировать через app server (надо чтоб были настроены сертификаты - это надо дополнительно проверять перед тем как рисовать кнопку и отправлять)
- скопировать каким-то простым способом прямо на ПК

Предложи какие простые варианты есть скопировать файл с телефона на ПК при условии, что они в одной сети. Надо чтобы было
и по коду просто и быстро и достаточно надёжно.
