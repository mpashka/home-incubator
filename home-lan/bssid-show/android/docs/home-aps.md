# Карта домашних точек доступа

Родитель: [`index.md`](index.md). Данные сняты с живого железа **07.08.2026**.

Площадка «Чернышевского-3», три точки на OpenWrt. Настройкой управляет соседний репозиторий:
`home-config-secrets @/ansible/.configs/group_vars/all.yml`, ключ `wifi_sites`; описание
схемы — `@/ansible/docs/wifi.md`.

## BSSID: все двенадцать

На каждом радио два SSID — общая роуминговая сеть и именная сеть точки. Каждый SSID это
отдельный BSS со своим BSSID.

## Закономерность, на которой стоит построить сопоставление

`@tag:ap-map`

Второй BSS радио получает **тот же MAC с выставленным битом локального администрирования**
(бит `0x02` первого байта): `40`→`42`, `d4`→`d6`. Поэтому:

1. сбрось бит `0x02` в первом байте BSSID;
2. сопоставь получившееся с таблицей из шести адресов.

```
40:31:3c:df:5c:3f  и  40:31:3c:df:5c:40   -> коридор  (l)
d4:da:21:71:10:21  и  d4:da:21:71:10:22   -> спальня  (b)
d4:da:21:71:10:06  и  d4:da:21:71:10:07   -> кухня    (k)
```

Так одна запись покрывает обе сети точки, а комната определяется независимо от того, в общей
сети телефон или в именной.

**Сопоставлять по префиксу нельзя.** Спальня и кухня — одинаковые роутеры одной партии, у них
совпадают первые пять байт (`d4:da:21:71:10`), различается только последний. Сравнивай адрес
целиком.

## Что меняется, а что нет

| | устойчивость |
|---|---|
| BSSID | меняются только при смене железа |
| SSID | меняются, если переименовать сети в реестре |
| каналы | **меняются регулярно** — подбираются командой `cfg wifi scan` по обстановке в эфире |
| соответствие комнате | меняется, если точку переставить в другую комнату |

Поэтому канал в приложении показывать не надо (устареет), а карту BSSID→комната держи
редактируемой — в ресурсе или в настройках, чтобы правка не требовала пересборки.

## Как свериться с правдой

С ноутбука, из репозитория `home-config-secrets`:

```bash
cfg wifi who                    # кто к какой точке подключён, с уровнем сигнала
cfg wifi who papa-phone --watch # следить за переходами конкретного телефона
```

Команда спрашивает сами точки, кто у них в assoclist, поэтому её ответ — эталон для проверки
виджета. Учти: assoclist иногда держит устаревшие записи, и одно устройство может на секунду
показаться сразу на двух точках.

Пересобрать эту таблицу после перенастройки:

```bash
for h in 1 2 3; do ssh root@192.168.2.$h '
  for d in $(iw dev | awk "/Interface/{print \$2}"); do
    iw dev $d info | awk "/^Interface/{i=\$2} /addr/{a=\$2} /ssid/{s=\$2} /channel/{c=\$2}
                          END{printf \"%-8s %-18s ch%s\n\", s, a, c}"
  done'; done
```
