# Фронтенд

Родительский индекс: [../docs/index.md](../docs/index.md) ·
Договор с бэкендом целиком: [../docs/specification/api.md](../docs/specification/api.md)

Веб-оболочка словаря: Vue 3 (Composition API, `<script setup>`), сборка Vite, обычный
JavaScript. Две страницы — поиск и карточка слова. Данные берутся у бэкенда
(Spring Boot, `http://localhost:8180`) через `/api`.

## Запуск

```bash
npm install
npm run dev                 # разработка, данные с бэкенда через перенаправление /api
VITE_MOCK=1 npm run dev     # разработка на заготовках, бэкенд не нужен
npm run build               # сборка в dist/
```

## Файлы

- `package.json` — зависимости и команды запуска
- `vite.config.js` — сборка; Vite на порту `8181`, перенаправление `/api` на бэкенд
  `localhost:8180`
- `index.html` — точка входа страницы

## Поддиректории

- `src/` — исходный код (описание ниже)

## src/

- `main.js` — создаёт приложение, подключает роутер и общее оформление
- `router.js` — маршруты: `/` — поиск, `/word/:name` — карточка слова
- `App.vue` — общая рамка: шапка, настройки и быстрые переключатели примеров, оборотов и корней
- `styles.css` — всё оформление; **здесь задан шрифт для текста с ударениями**
- `labels.js` — русские названия для кодов части речи и состояния статьи
- `settings.js` — сохранённые в браузере настройки алфавита, темы, разделов карточки и словоформ
- `grammar-help.js` — состояние всплывающей памятки по грамматике
- `serbian.js` — преобразование сербской кириллицы в латиницу для показа

### src/api/

- `dictionary.js` — единственное место обращения к бэкенду: поиск и карточка слова;
  здесь же заготовки данных для работы без бэкенда (`VITE_MOCK=1`)

### src/pages/

- `SearchPage.vue` — поиск по мере набора (задержка 250 мс), список найденного;
  запрос хранится в адресе страницы (`?q=`), поэтому возврат с карточки его восстанавливает
- `WordPage.vue` — карточка слова: пометы с подсказками, формы с падежными фразами и правилом,
  значения, обороты и корни

### src/components/

- `Accented.vue` — показ сербского текста с ударениями; через него идёт **весь** сербский текст
- `SerbianText.vue` — сербский текст с ссылками на слова словаря
- `GrammarHelp.vue` — всплывающая справка с правилами падежей, глаголов, местоимений
  и прилагательных; кратко пересказывает указанные разделы учебника
- `Notice.vue` — короткое сообщение вместо содержимого: ожидание, «не найдено», ошибка

## Про ударения

Заглавные слова приходят кириллицей с комбинируемыми знаками, отдельными код-точками:
U+0300 (краткое восходящее), U+0301 (долгое восходящее), U+030F (краткое нисходящее),
U+0311 (долгое нисходящее), U+0304 (заударная долгота). Готовых слитных символов
«кириллическая буква со знаком ударения» в Юникоде нет, поэтому отрисовка целиком
держится на шрифте и на том, что знак не отрывается от буквы.

Отсюда два правила, оба закреплены в классе `.accented` (`styles.css`):

- шрифт берётся из ряда с полным покрытием этих знаков:
  `"Charis SIL", "Gentium Plus", "DejaVu Serif", "Noto Serif", "Liberation Serif", serif`.
  Первые два — лучшие для сербского, но их может не быть в системе; из обычно
  установленных все нужные знаки покрывают DejaVu Serif, Noto Serif и Liberation Serif;
- `letter-spacing` для такого текста **не задаётся** — лишний зазор отрывает знак от
  буквы; кернинг и лигатуры остаются включёнными, на них держится и расстановка знака
  над буквой, и наложение двух знаков друг над другом (например U+030F + U+0304).

Проверено отрисовкой в браузере: все пять знаков по отдельности и сочетания
U+030F + U+0304, U+0311 + U+0304, U+0301 + U+0304 встают друг над другом ровно.

## Договор с бэкендом

Владелец описания — [../docs/specification/api.md](../docs/specification/api.md); здесь
только то, что важно для оболочки:

- `GET /api/words?q={запрос}&limit=20` → `{ items: [{ name, headword, translations }], total }`
- `GET /api/words/{name}` → карточка слова; `404`, если слова нет

Поля `partOfSpeech`, `grammar`, `idioms`, `number`, `examples` могут прийти пустыми
или отсутствовать — страницы это переживают.
