# Фронтенд

Родительский индекс: [../docs/index.md](../docs/index.md) ·
Договор с бэкендом целиком: [../docs/specification/api.md](../docs/specification/api.md)

Веб-оболочка словаря: Vue 3 (Composition API, `<script setup>`), сборка Vite, обычный
JavaScript. Две страницы — поиск и карточка слова. Данные берутся у бэкенда
(Spring Boot, `http://localhost:8180`) через `/api`.

## Запуск

```bash
npm install
npm run dev                 # разработка, данные с бэкенда через перенаправление /api
VITE_MOCK=1 npm run dev     # разработка на заготовках, бэкенд не нужен
npm run build               # сборка в dist/
npm test                    # преобразование алфавита, пометы форм, разбор по правилу
```

## Файлы

- `package.json` — зависимости и команды запуска
- `vite.config.js` — сборка; Vite на порту `8181`, перенаправление `/api` на бэкенд
  `localhost:8180`
- `index.html` — точка входа страницы

## Поддиректории

- `src/` — исходный код (описание ниже)

## src/

- `main.js` — создаёт приложение, подключает роутер и общее оформление
- `router.js` — маршруты: `/` — поиск, `/word/:name` — карточка слова; переход по
  щелчку добавляет `?id=`, и тогда открывается ровно выбранное слово
- `App.vue` — общая рамка: шапка, настройки и панель переключателей — поиск по
  словоформам, примеры, обороты, связь с корнями
- `styles.css` — всё оформление; **здесь задан шрифт для текста с ударениями**
- `labels.js` — названия для кодов части речи, состояния статьи и **помет словоформ**:
  `gen.sg` → «родительный падеж, единственное число» по-русски, «Genitiv jednine»
  по-сербски, `formLabel` собирает подпись по настройке. Один владелец расшифровки на
  весь показ: карточка и справка подписывают падеж одинаково
- `settings.js` — сохранённые в браузере настройки: алфавит показа и поиска, тема,
  поиск по словоформам, вид названий падежей, разделы карточки и разделы справки
  по правилу
- `grammar-help.js` — состояние справки: общий раздел либо правило конкретной формы
- `serbian.js` — преобразование сербской кириллицы в латиницу для показа
- `grammar-rules.js` — правила склонения в читаемом виде: окончания по типам, примеры,
  исключения и разбор формы на основу с окончанием

### src/api/

- `dictionary.js` — единственное место обращения к бэкенду: поиск, статья по написанию
  (`loadWord`) и статья по идентификатору слова (`loadWordById`); здесь же заготовки
  данных для работы без бэкенда (`VITE_MOCK=1`)

### src/pages/

- `SearchPage.vue` — поиск по мере набора (задержка 250 мс), список найденного;
  запрос хранится в адресе страницы (`?q=`), поэтому возврат с карточки его восстанавливает.
  У найденного по словоформе показывает саму форму и её падеж, а ссылка ведёт по `id`
  слова — правило «щелчок ведёт ровно в то слово»
  ([ui.md](../docs/specification/ui.md))
- `WordPage.vue` — карточка слова: пометы с подсказками, формы с падежными фразами и
  правилом, значения, обороты и корни. Открывает слово по `id`, если он есть в адресе;
  когда статья нашлась по словоформе, говорит об этом и называет, чья это форма

### src/components/

- `Accented.vue` — показ сербского текста с ударениями; через него идёт **весь** сербский текст
- `SerbianText.vue` — сербский текст с ссылками на слова словаря
- `GrammarHelp.vue` — всплывающая справка: общие разделы (падежи, глаголы, местоимения,
  прилагательные) и **правило конкретной формы** — окончания, парадигма слова из его же
  карточки, разбор формы, примеры и исключения; разделы правила переключаются своей
  панелью
- `Notice.vue` — короткое сообщение вместо содержимого: ожидание, «не найдено», ошибка

## Про ударения

Заглавные слова приходят кириллицей с комбинируемыми знаками, отдельными код-точками:
U+0300 (краткое восходящее), U+0301 (долгое восходящее), U+030F (краткое нисходящее),
U+0311 (долгое нисходящее), U+0304 (заударная долгота). Готовых слитных символов
«кириллическая буква со знаком ударения» в Юникоде нет, поэтому отрисовка целиком
держится на шрифте и на том, что знак не отрывается от буквы.

Отсюда два правила, оба закреплены в классе `.accented` (`styles.css`):

- шрифт берётся из ряда с полным покрытием этих знаков:
  `"Charis SIL", "Gentium Plus", "DejaVu Serif", "Noto Serif", "Liberation Serif", serif`.
  Первые два — лучшие для сербского, но их может не быть в системе; из обычно
  установленных все нужные знаки покрывают DejaVu Serif, Noto Serif и Liberation Serif;
- `letter-spacing` для такого текста **не задаётся** — лишний зазор отрывает знак от
  буквы; кернинг и лигатуры остаются включёнными, на них держится и расстановка знака
  над буквой, и наложение двух знаков друг над другом (например U+030F + U+0304).

Проверено отрисовкой в браузере: все пять знаков по отдельности и сочетания
U+030F + U+0304, U+0311 + U+0304, U+0301 + U+0304 встают друг над другом ровно.

## Договор с бэкендом

Владелец описания — [../docs/specification/api.md](../docs/specification/api.md),
обязательства перед читающим — [../docs/specification/ui.md](../docs/specification/ui.md);
здесь только то, что важно для оболочки:

- `GET /api/words?q={запрос}&limit=20&forms={true|false}` → `{ items: [{ id, name, headword,
  translations, matchedForm }], total }`
- `GET /api/words/id/{id}` и `GET /api/words/{name}` → `{ matchedBy, words }`; `404`,
  если ничего не нашлось

Поля `partOfSpeech`, `grammar`, `idioms`, `number`, `examples`, `matchedForm` могут прийти
пустыми или отсутствовать — страницы это переживают.

## Проверки

`npm test` — узлы, которые можно проверить без браузера: преобразование кириллицы в
латиницу (`test-serbian.mjs`), расшифровка помет и разбор формы по правилу
(`test-grammar.mjs`). Страницы не покрыты, см.
[../docs/testing/index.md](../docs/testing/index.md).
