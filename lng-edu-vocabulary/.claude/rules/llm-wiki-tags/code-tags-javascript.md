# llm-wiki-tags — тэги в JavaScript и Vue

Токен `@tag:<slug>` ставится в комментарии прямо над маркируемым элементом.
Подходит любой стиль — `//`, `/* */` или JSDoc; там, где у элемента уже есть
JSDoc, ставь тэг в него, чтобы тэг шёл вместе с документацией. Несколько тэгов —
через пробел. Формат и реестр: [`tags.md`](tags.md).

- **Директория** (аналог пакета) — тэг в её `index.md`, отдельного файла с кодом
  под это не заводят.
- **Файл** — комментарий в самом верху файла, до первого `import`:
  ```js
  // @tag:accent
  import { ref } from 'vue'
  ```
- **Однофайловый компонент Vue** (`.vue`) — комментарий первой строкой блока
  `<script setup>`; тэг всего компонента ставится именно там, а не в `<template>`:
  ```vue
  <script setup>
  // @tag:accent
  ...
  </script>
  ```
- **Класс, компонент, функция** — прямо над объявлением:
  ```js
  /** Переводит сербскую кириллицу в латиницу. @tag:accent */
  export function toLatin(text) { ... }
  ```
