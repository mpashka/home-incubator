# Внешние материалы по сербскому языку

Родительский индекс: [index.md](index.md)

Помимо исходной базы приложения ([source-db.md](source-db.md)) и
викисловаря ([wiktionary.md](wiktionary.md)) есть ещё словари, грамматики и учебники.
Их можно использовать для проверки и восполнения: разделения омонимов, ударений
в словоформах, определения части речи.

Все они лежат **вне репозитория** (крупные, под чужими правами):
`~/Projects/.../lng-edu-vocabulary/.data/` и `~/Documents/Srpski/`. Каталог `.data/`
внесён в `.gitignore`.

## Сайты-источники

### serblang.ru

**<https://serblang.ru/>** — хороший источник: словари и **сербская литература**.
Литература особенно ценна для проверки: живые тексты показывают, как слово
употребляется на деле, и годятся для примеров. Отсюда взят словарь Толстого.

Проверить и разобрать: какие ещё словари там выложены, в каком виде (текст или сканы),
что из литературы можно использовать для сверки словоупотребления и для этапа импорта книги.

### rutracker.org

**<https://rutracker.org/>** — торренты; потенциально там лежат словари, грамматики
и озвученные материалы, которых нет в открытом доступе. Проверить, что есть полезного
по сербскому языку, и оценить пригодность.

## Словарь Толстого

Сербскохорватско-русский словарь под ред. И. И. Толстого — самый авторитетный из
имеющихся. Лежит в `.data/tolstoj/` в двух видах:

| Вид | Путь | Годность |
|---|---|---|
| Картинки страниц | `SERB_HOR/DATA/*.jpg` (668 шт., 1033×1708, серые, 150 dpi) | читаемы глазом |
| PDF с «текстовым слоем» | `Tolstoj.Sh-r slovar.pdf` (585 стр.) | **текстовый слой негоден** |

**Важно, проверено:** текстовый слой PDF — это шум (`ЕЁЁЁ ЕзЕЕ ЕЕЁЕЕ`), а не
распознанный текст, вопреки описанию на сайте-источнике. `pdftotext` осмысленного
текста не даёт ни на одной странице. Чтобы взять текст из словаря Толстого, страницы
надо **распознавать заново** по картинкам — это отдельная задача, не «взять готовое».

Есть и `.djvu`-версия: `~/Documents/Srpski/Recnik/Srb-Rus/Толстой… 2001.djvu`.

Ценность словаря Толстого: у него **аккуратная типографика с ударениями и чёткое
разделение омонимов** римскими цифрами — как раз то, чего не хватает исходной базе.

## Что с этим делать

Для всплывающей грамматической справки уже использованы соответствующие разделы
Просвириной (§5.2.3–5, §5.3, §5.4.1, §5.6.1–2 и §5.6.17) и пособие Краишник для
значений падежей. В интерфейс внесён краткий пересказ правил и собственные примеры,
а не текст учебника целиком.

Оценка каждого материала и решение, использовать ли его, — пункт плана
([plan.md](../plan.md), этап 6). Отдельно стоит задача снятия неоднозначностей
(омонимы, словоформы, части речи) — [requests/word_investigate](../requests/word_investigate/request.md).
