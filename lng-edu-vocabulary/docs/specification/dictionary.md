## Возможности

| Возможность | Состояние |
|---|---|
| Поиск по **любой словоформе** сербского слова, а не только по заглавному | есть: 324 511 форм в указателе — полная регулярная парадигма с пометой каждой формы |
| Поиск по русскому переводу, ввод кириллицей и латиницей | есть, режим выбирается настройкой |
| **Ударение** у заглавного слова и у словоформ | у заглавных есть; у словоформ достоверно лишь для 8 648 выписанных в исходном словаре — остальные ждут внешнего источника ([../implementation/word-forms.md](../implementation/word-forms.md)) |
| **Разные значения одного слова** показаны раздельно | есть там, где в исходной базе была нумерация (28 % статей); для остальных отложено до разбора моделью |
| **Омонимы** — самостоятельные слова под одним написанием — показаны раздельно | есть: 1 268 статей разделены на 2 654 слова, у каждого своё ударение |
| Примеры употребления и устойчивые обороты | есть: 11 792 записи |
| **Часть речи** | есть у 99,7 % статей ([../implementation/part-of-speech.md](../implementation/part-of-speech.md)) |
| **Связь с корнями**: русским, сербским, праславянским | таблица заведена, сведений пока нет — этапы 6 и 10 плана |
| Пополнение словаря языковой моделью для слов, которых в базе нет | не сделано, этап 10 |
| Импорт книги и двуязычный перевод для чтения | не сделано, этап 11 |

Слова, которые словарь показывает, — из сербско-русского словаря Android-приложения:
45 633 статьи ([../implementation/source-db.md](../implementation/source-db.md)).

## Состояние слова видно снаружи

У каждого слова есть состояние обработки, и словарь его не скрывает: `NO_TRANSLATION`
(перевода нет, слово в очереди на разбор моделью), `IMPORTED` (перенесено из старого
словаря), `AWAITING_REVIEW` (разобрано моделью или внешним источником, ждёт проверки),
`COMPLETE` (обработано полностью, включая связь с корнями).

Рядом отметка `needsLanguageReview` с причиной: по слову остались языковые пробелы —
не разделены значения, не определена часть речи, нет ударения. Так помечено 356 слов
(0,8 %). Это осознанное решение: сведение с неизвестной достоверностью показывается
с оговоркой, а не выдаётся за проверенное. Степени доверия к источникам —
[../implementation/db-schema.md](../implementation/db-schema.md).

## Как показывается сербский текст

Заглавные слова и формы отдаются кириллицей с **комбинируемыми знаками ударения**
Unicode (U+0300, U+0301, U+030F, U+0311, U+0304), латиница выводится из кириллицы
преобразованием. Обратное направление неоднозначно (`nj` — это и `њ`, и `нј`), поэтому
источником латиница быть не может. Требования к шрифту и отрисовке — в
[../../frontend/index.md](../../frontend/index.md), раздел «Про ударения».
