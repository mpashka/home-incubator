# REST API словаря

Родительский индекс: [index.md](index.md)

Бэкенд слушает `http://localhost:8180`. Фронтенд в разработке перенаправляет на него
всё, что начинается с `/api`.

Данные читаются из **Postgres** — словарь перенесён туда конвертером
(`./gradlew :importer:migrate`, см. [db-schema.md](../implementation/db-schema.md)).

## Поиск

```
GET /api/words?q={запрос}&limit={сколько}&alphabet={режим}
```

`q` — начало сербского слова (кириллицей либо латиницей), **любая его словоформа**
либо русский перевод. `limit` по умолчанию 20, не больше 100. `alphabet` задаёт
режим поиска: `separate` — кириллица ищет только русский перевод, латиница — сербское
слово и словоформы; `any` — оба направления при любом алфавите; `current` (по умолчанию)
— кириллица ищет оба направления, латиница — сербское.

```json
{
  "items": [
    { "name": "вода", "headword": "во̀да", "translations": ["вода́", "река́"] }
  ],
  "total": 1
}
```

`name` — ключ статьи: **кириллица без ударений**, с ним обращаются за карточкой.
В адресе его надо кодировать (`/api/words/%D0%B2%D0%BE%D0%B4%D0%B0`).

## Карточка слова

```
GET /api/words/{name}
```

`404`, если статьи нет.

```json
{
  "name": "вода",
  "headword": "во̀да",
  "headwordLatin": "vòda",
  "grammar": ["ж"],
  "partOfSpeech": "NOUN",
  "forms": [ { "form": "во̀де", "grammar": "dat.sg", "source": "RULES", "rule": "noun-declension" } ],
  "roots": [],
  "senses": [
    { "number": 1,
      "translations": ["вода́"],
      "examples": [ { "serbian": "слатка во̀да", "russian": "пре́сная вода́" } ] }
  ],
  "idioms": [ { "serbian": "велика во̀да", "russian": "полово́дье, разли́в" } ],
  "status": "IMPORTED",
  "needsLanguageReview": false,
  "reviewReason": null
}
```

`number` равен `null`, если в исходной статье нумерации значений не было — таких
статей 72 %. `partOfSpeech` может быть `UNKNOWN`. `grammar` — пометы без завершающей
точки (`ж`, а не `ж.`); точка ставится при показе.

Поля первого омонима лежат на верхнем уровне, а полный список — в `homonyms`
(у каждого свои `senses`, `forms`, `idioms`, `roots`, `partOfSpeech` и `homonymIndex`). Под одним
написанием бывает несколько самостоятельных слов: `бити` — «быть» и «бить».

`forms` содержит известные словоформы с обозначением грамматики и источником; `RULES`
означает форму, полученную правилом и требующую языковой проверки. У таких форм поле
`rule` содержит ссылочный ключ правила. `roots` содержит
связи с русским, сербским, праславянским, праиндоевропейским либо другим корнем;
сейчас таблица корней ещё не заполнена. Адрес карточки принимает также сербскую
словоформу, поэтому слова в сербских примерах можно связывать с их статьями.

`needsLanguageReview` — по слову остались отложенные языковые пробелы, а `reviewReason`
перечисляет какие («омонимы не разделены», «значения не разделены», «часть речи не
определена»). Таких слов 37 %; оттачивание качества отложено, см. [plan.md](../plan.md), этап 6.

Значения полей: `partOfSpeech` — `NOUN`, `VERB`, `ADJECTIVE`, `ADVERB`, `PRONOUN`,
`NUMERAL`, `INTERJECTION`, `CONJUNCTION`, `PREPOSITION`, `PARTICLE`, `UNKNOWN`;
`status` — `NO_TRANSLATION`, `IMPORTED`, `AWAITING_REVIEW`, `COMPLETE`.

## Ударения в ответах

Ударения приходят **комбинируемыми знаками Unicode**, то есть уже готовыми к показу,
а не служебными знаками исходной базы.

| Что | Знак | Пример |
|---|---|---|
| краткое восходящее | U+0300 | во̀да |
| долгое восходящее | U+0301 | ру́ка |
| краткое нисходящее | U+030F | бра̏т |
| долгое нисходящее | U+0311 | ма̑јка |
| заударная долгота | U+0304 | јуна̄к |
| русское ударение | U+0301 | вода́ |

Русское ударение в исходной базе записано тем же символом U+2019, что и сербское долгое
восходящее; различить их можно только по помете фрагмента, поэтому преобразование делается
раздельно — `Serbian.renderAccents` и `Russian.renderStress`. Наружу отдаётся уже готовый вид.

Шрифт на стороне показа обязан покрывать эти знаки, иначе будут квадраты. Подходят
DejaVu Serif, Noto Serif, Liberation Serif.
